# Kindle PDF 排版工具｜买家使用说明

第一次使用：下载对应版本 → 安装并打开 → 添加 PDF → 预览排版 → 导出文件。
三个版本的使用方法相同，只需下载与你电脑对应的一个安装包。

## 一、我应该下载哪个版本？

- Windows 电脑（Intel / AMD，64 位）：Windows版.zip
- Intel 芯片的 Mac：Mac版（Intel）.dmg
- Apple M 系列芯片的 Mac：Mac版（M系列）.dmg

不知道 Mac 属于哪种？
点击屏幕左上角“苹果菜单 → 关于本机”：
显示“芯片 Apple M…”选 M 系列版；显示“处理器 Intel…”选 Intel 版。
两个 Mac 版本均需要 macOS 14 或更新系统。旧系统请先联系卖家确认。

## 二、Windows 如何安装和打开？

1. 下载“Windows版.zip”。
2. 右键压缩包，选择“全部解压缩”，解压到电脑上的固定文件夹。
3. 打开解压后的文件夹，双击“双击启动_Kindle精排大师.bat”。
4. 等待浏览器自动打开排版工作台。

不要直接在压缩包内运行，也不要只把 EXE 单独拖出来。
请保留解压后的全部文件。运行时出现的命令窗口请保持打开。
本安装包已包含运行所需组件，无需另行安装 Python。

## 三、Intel Mac 如何安装和打开？

1. 下载“Mac版（Intel）.dmg”。
2. 双击打开 DMG，把“KPW6 PDF Studio”拖入“应用程序”。
3. 等待复制完成，再到“应用程序”中双击打开软件。
4. 等待浏览器自动打开排版工作台。

## 四、M 系列 Mac 如何安装和打开？

1. 下载“Mac版（M系列）.dmg”。
2. 双击打开 DMG，把“KPW6 PDF Studio”拖入“应用程序”。
3. 等待复制完成，再到“应用程序”中双击打开软件。
4. 等待浏览器自动打开排版工作台。

Mac 安装完成后可推出 DMG，之后从“应用程序”启动即可。
当前 Mac 版本尚未完成 Apple 公证；如出现“无法验证开发者”等阻止打开的提示，请截图联系卖家处理。

## 五、打开以后怎么用？

### 第 1 步：添加 PDF
点击“点击上传或将 PDF 拖到这里”，选择自己的 PDF 文件。
这里的“上传”是把文件交给本机软件处理，不是传到本软件的云端。

### 第 2 步：选择文档类型
- 左右两栏的论文：选“双栏学术论文”。
- 有公式、表格和插图的书：选“带图表的专业书”。
- 扫描、拍照形成的 PDF：选“扫描版书籍”。
- 漫画或画册 PDF：选“PDF 漫画 / 纯图画册”。
- 能选中、复制文字的小说或长文：选“纯文字 PDF 书籍”。

### 第 3 步：查看预览
第一次先用默认参数，检查正文、图表和阅读顺序。
文字太小、白边太多或图表被切开时，再调整对应设置。
复杂图表可以设置为整页保留；若正文被误当成页眉页脚删去，可关闭“自动剔除页眉与页码页脚”。
第一次建议先导出几页试读，效果合适后再导出全书。

### 第 4 步：选择导出格式
- 想保留图表、公式与页面布局：选 PDF 或“EPUB 精排”。
- 纯文字书，希望在阅读器中调整字号：选“EPUB 流式”。
- AZW3 / MOBI：需要另外安装 Calibre；不使用这两种格式可忽略。
- CBZ：供支持该格式的漫画阅读器使用。

### 第 5 步：导出并找到文件
选好格式和页码范围，点击“一键导出”，等待完成。
再点击页面顶部“打开导出目录”，找到生成的文件。
软件会生成新文件，不会覆盖你的原始 PDF。

## 六、怎么放到 Kindle 阅读？

如果你的 Amazon 账号和设备支持 Send to Kindle：
打开 https://www.amazon.com/sendtokindle ，登录与 Kindle 对应的账号，添加导出的 PDF 或 EPUB，发送后让 Kindle 联网同步。

使用 USB 传书时，请按照你的 Kindle 型号对应的官方方法传入支持的格式。
Mac 连接部分较新的 Kindle 时需要额外的传输工具，并非所有型号都会直接显示成 U 盘。
EPUB 请通过支持的传书服务转换，不要仅修改文件后缀。

建议先传几页试读，确认字体、图表与翻页效果后再处理整本书。
传书服务是否可用取决于账号地区和设备；书架封面、锁屏封面与显示效果也可能因设备而异。
官方传书说明：https://www.amazon.com/gp/help/customer/display.html?nodeId=G5WYD9SAF7PGXRNA

## 七、常见问题

1. 为什么打开的是浏览器？
这是软件的正常界面，排版处理在本机进行。导出或预览时请保持软件运行。

2. Mac 关闭网页后，怎么重新打开？
点击屏幕顶部菜单栏的“📖 KPW6精排”，选择“打开 Kindle 精排工作台”。
使用完毕后，可在同一菜单中选择“退出 Kindle 精排大师”。

3. Windows 使用完毕怎么退出？
先等待导出完成，再关闭网页和启动时出现的命令窗口。

4. PDF 无法导入怎么办？
先确认原文件能正常打开。需要密码的文件请先在有权限的情况下另存为无密码 PDF；损坏文件请重新下载。

5. 为什么扫描件不能变成可调字号的文字书？
扫描件通常是图片。本工具的扫描模式主要改善图片版面和清晰度，不会自动把图片识别成正文文字。

6. 导出慢或文件太大怎么办？
扫描件、高清图片和长篇文档需要更多时间。可以先缩小导出页码范围，或使用分卷、降低输出清晰度。

7. 更新版本怎么处理？
先退出软件，再按对应平台重新安装或完整解压新版。更新前保留原始 PDF 和已经导出的文件。

遇到问题联系卖家时，请提供：电脑系统、Mac 芯片类型（如适用）、报错截图，以及出现问题的操作步骤。
